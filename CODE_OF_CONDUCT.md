# Code of Conduct

## Expected Behavior

Participants should be respectful, direct, and focused on improving the project. Technical disagreement is welcome. Personal attacks, harassment, and discriminatory behavior are not.

## Unacceptable Behavior

Unacceptable behavior includes harassment, threats, sustained disruption, sexualized language or imagery, discriminatory comments, and publishing private information without permission.

## Enforcement

Maintainers may remove comments, close issues, block participants, or take other reasonable steps to protect the project community.

## Reporting

Report serious conduct issues privately through the maintainer contact listed in the repository security policy when public discussion is not appropriate.
